### Steps to reproduce

1.  Login as a user with permissions to create new work packages in a project

2.  navigate to a project with a _boards_ module enabled

3.  add a work package to a random board

4.  select this work package, use a right click and select _duplicate_

5.  Duplicate the work package


### What is the buggy behavior?

*   When a user duplicates a work packages from within a board, they will be moved to the work packages list automatically instead of staying in the previous selected boards view.


### What is the expected behavior?


1.  A user who works with a board expects to stay in that board when action with work packages in that certain board happen (e.g. duplication)


### Further notes

The expected behavior was the standard behavior up until recently (probably 14.5). Maybe it changed together with the renaming of copy -&gt; duplicate?
I tested it with a 14.4.x community version where it still works as expected above.
