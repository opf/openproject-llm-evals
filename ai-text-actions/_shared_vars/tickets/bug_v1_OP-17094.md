### Steps to reproduce

1.  Login as a user with permissions to create projects and projects attributes.

2.  Ensure there is at least one existing project in the system:

    1.  Click the green + in the top-left hand corner, then **\+ Project**

    2.  Fill in **Name** (e.g. Example Project) and any other required fields.

    3.  Click on &quot;Save&quot;

    4.  The project should be saved. You should be redirected to the Project Overview page for the newly-created project.

3.  Create a **new project attribute that is required for all projects**

    1.  Click on the avatar in the right-hand corner, then **Administration**.

    2.  From the administration page, click **Projects**. Then click **Project attributes**.

    3.  Click the green **\+ Project attribute.**

    4.  Fill in **Name** (e.g. New Project Attribute).

    5.  Select a default Section.

    6.  Check **Required for all Projects**

    7.  Click **Save**.

4.  Select the previously created project in the project selector at the top of the page.

5.  Click **Project** **settings**.

6.  Click **Change Identifier**

7.  Type in a new identifier and click **Update**.


### What is the buggy behavior?

*   An error message is displayed &quot;New project attribute can&#39;t be blank&quot;
